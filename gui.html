Basic flow
  1. 1. Launch Open this screen with run-gui.bat and keep the command window running.
  2. 2. Prepare Create a blank destination database, then keep Tally Prime open with the target company loaded.
  3. 3. Connect In Tally, enable Client/Server connectivity as Both, usually on port 9000.
  4. 4. Configure Fill database and Tally details, then use Check Tally Status and reload the company list.
  5. 5. Run Choose full or incremental sync, set the period, and click Sync.
  6. 6. Verify Watch the live log below. Tables are created automatically; detailed failures go to error-log.txt.
